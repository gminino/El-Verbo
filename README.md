# El Verbo como Co-regulador Primario

**Autor:** Guillermo Emigdio Miniño Álvarez
**Proyecto:** Kninord Animal Training / Club Paraíso Animal
**Ubicación:** Villa Soñador, Bonao, República Dominicana

## Descripción
Tesis integradora que explora el Verbo —en su dimensión ontológica, neurobiológica y espiritual— como mecanismo primario de co-regulación del sistema nervioso y la memoria. El marco se aplica a distintos dominios de la experiencia humana —incluyendo el trauma transgeneracional como uno de los casos de estudio (Cap. 2)— dentro de un modelo orientado primariamente a la regulación en seres sanos.

El trabajo integra:
- Teoría Polivagal (Porges)
- Reconsolidación de memoria (Nader)
- Transmisión epigenética del trauma (Yehuda, Meaney) — antecedente teórico, desarrollado en el Cap. 2
- Juan 1:1 como ancla teológica
- Shaolin y la TCM como plataformas de práctica verificable
